Stick Figure to Animation — Team 04

Open index.html in Chrome or Edge. Upload an image and align the editable skeleton joints over it. The uploaded image is a reference layer only; the skeleton is what animates.

The original scenic background (sun, clouds, mountains and landscape) is preserved. PNG, GIF and video exports omit the uploaded reference image and use the scenic background. Use Hide original image to switch back to the scenic background in the editor too. WebM export is supported by many modern browsers. MP4 export is offered only when the browser supports MP4 recording; if not, use WebM and convert it with a video converter. GIF export requires internet access to load its encoder.

This prototype does not automatically deform or animate the uploaded image pixels. The uploaded image is used to align the editable stick figure.
