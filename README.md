# Stick Figure to Animation — Team 04

A browser-based stick-figure animation prototype.

## Project files
- `index.html` — page structure and application entry point
- `css/style.css` — styling and responsive layout
- `js/app.js` — animation, canvas drawing, controls, and export logic

## Run locally
Open `index.html` in a modern browser. The GIF export library is loaded from the jsDelivr/CDNJS-hosted CDN URL already included in `index.html`, so an internet connection is needed for that library.

## Publish with GitHub Pages
Upload `index.html`, the `css` folder, the `js` folder, and this README to the root of your GitHub repository. Then go to **Settings → Pages**, choose the main branch and root folder, and save.

## Note
This is a prototype; features depend on browser support.
